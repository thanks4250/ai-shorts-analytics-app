무엇을 읽나

이 도구는 채널 운영자가 직접 승인한 경우에만 YouTube Analytics API와 YouTube Data API로 그 채널의 영상 통계(조회수, 시청 시간, 좋아요, 구독 증감, 트래픽 소스)와 영상 정보를 읽기 전용으로 가져옵니다.

어떻게 쓰나

가져온 통계는 운영자 본인의 콘텐츠 제작 기록을 위해서만 씁니다. 다른 사람의 데이터는 수집하지 않으며, 데이터를 판매하거나 광고에 쓰거나 제3자에게 넘기지 않습니다. 어떤 데이터도 쓰거나 바꾸지 않습니다.

보관과 삭제

통계는 운영자의 비공개 작업 저장소에만 보관합니다. 운영자는 Google 계정의 '타사 액세스' 설정에서 언제든 접근 권한을 철회할 수 있습니다.

Google API 서비스 사용자 데이터 정책

This app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It requests read-only access to the owner's own YouTube channel analytics, uses it only for the owner's own content records, and does not sell, transfer, or use the data for advertising.
